# Inventario
Programa en consola realizado por medio de Javascript para la compra, venta y control de los productos en inventarios, para lo cual se creó un Map con el inventario y datos sobre cada uno de los productos. Las funciones son:
- Venta de Productos: La función recibe el código del producto y la cantidad de unidades a vender    mostrandole al usuario si es posible realizar la venta de acuerdo a la cantidad de unidades disponibles, de ser posibles se realizará la actualización en la cantidad del producto.
- Compra de Productos: Así como la anterior función recibe el código del producto y la cantidad de unidades a comprar, mostrandole al usuario la cantidad del producto actualizada.
- Totalizar Inventario: En esta función se recorre todo el inventario por cada producto se conoce el valor equivalente al stock del mismo este valor se incrementa en el valor del inventario. Al realizar el proceso con todos los productos, el programa muestra el valor total del inventario.
